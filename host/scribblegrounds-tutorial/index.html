How to make a custom map for Scribble Grounds

Custom maps are GLB files sent from the server to the client when they join. A map is made of a bunch of objects, and each drawable object, when loaded in the game, has a 1024x1024 texture that can be drawn on by players.

It's recommended to make a map in blender and export it as a GLB file that way.

Each drawable object MUST:

  • Be a separate object in blender with its transforms applied (position at 0, 0, 0, no rotation, scale 1, etc).
  • Have two UV maps - the first one for the drawing texture, and the second one for the baked lightmap or texture details, in that order (this allows you to use one lightmap texture for multiple objects)
    (The drawing texture UV map must not overlap itself, otherwise people's drawings will be duplicated elsewhere on the object)

If you want an object to not have drawing functionality, simply make its position in the world be something other than 0, 0, 0.

Correctly defined drawable objects automatically get colliders when imported, but non-drawable objects do not. To add a collider to a non-drawable object, include the hint "-col" in its name.
